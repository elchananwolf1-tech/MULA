חיבור WooCommerce

הפרטים האלו מאפשרים לטעון, ליצור, לערוך ולמחוק מוצרים.

נדרש
כתובת אתר WordPress שבו פועל WooCommerce, כולל https:// וללא נתיב של API.
ℹ️
יצירת מפתחות: בלוח הניהול של WordPress היכנס ל־WooCommerce ← הגדרות ← מתקדם ← REST API, לחץ על הוספת מפתח, בחר משתמש והרשאת Read/Write, והעתק לכאן את ה־Consumer Key וה־Consumer Secret.

העלאת תמונות מהמחשב

נדרש רק אם רוצים להעלות תמונה חדשה או להחליף תמונה קיימת.

אופציונלי, מומלץ
שם המשתמש לכניסה ללוח הניהול — לא כתובת האימייל בהכרח.
זו לא סיסמת הכניסה הרגילה. אפשר לבטל את סיסמת היישום בכל עת ב־WordPress.
🖼️
כדי להעלות תמונה מהמכשיר יש ליצור סיסמת יישום ב־WordPress: משתמשים ← פרופיל ← סיסמאות יישום (Application Passwords). הזן שם כמו Product Manager, לחץ על הוספת סיסמת יישום והעתק אותה לכאן. משתמש זה צריך הרשאה להעלאת מדיה ולניהול מוצרים.
🔐
חשוב בנושא אבטחה: LocalStorage נוח, אבל אינו כספת. כל מי שיש לו גישה לפרופיל הדפדפן או לקוד JavaScript שרץ באתר עלול תאורטית לגשת לפרטים. השתמש באתר HTTPS, שמור את הקובץ והמפתחות מחוץ למאגר ציבורי, אל תשתף משתמשים אחרים באותו ממשק עם מפתחות מנהל, וצור מפתחות בהרשאות המינימליות הנדרשות. לארגון או לאתר רב־משתמשים מומלץ להשתמש בשרת מתווך מאובטח.
השינויים לא נשמרו עד ללחיצה על שמירת הגדרות.

הוראות חיבור והפעלה

הגדרה ראשונית בכמה צעדים, ללא התקנת תוכנה נוספת.

חיבור WooCommerce

צריך גישה ללוח הניהול של חנות WordPress שלך.

1

פתח את לוח הניהול

היכנס ל־WordPress של החנות שלך, ובתפריט הצד לחץ על WooCommerce, לאחר מכן על הגדרות.

2

מצא את REST API

בחר בלשונית מתקדם (Advanced) ואז REST API. לחץ על Add key / הוסף מפתח.

3

הפק מפתח עם הרשאה מתאימה

תן תיאור, בחר משתמש מורשה, ובחר הרשאת Read/Write. לחץ על יצירת המפתח. העתק מיד את ה־Consumer Key ואת ה־Consumer Secret — הסוד לא יוצג שוב.

4

שמור ובדוק חיבור

חזור לכאן, פתח הגדרות וחיבור, הדבק את כתובת החנות ואת שני המפתחות, ואז לחץ על שמירת הגדרות וחיבור.

5

הגדר תמונות (רק אם צריך)

ב־WordPress היכנס ל־משתמשים ← פרופיל, חפש Application Passwords, צור סיסמה חדשה והעתק אותה יחד עם שם המשתמש להגדרות כאן.

6

ניהול מוצרים

פתח את המוצרים שלי. אפשר לחפש, להוסיף מוצר, לערוך שם/תיאור/מחיר/תמונה או למחוק מוצר. מחיקה כאן מבצעת מחיקה קבועה ב־WooCommerce.

איך לפרסם ב־GitHub Pages

האפליקציה היא קובץ HTML יחיד ואינה זקוקה לבנייה או להתקנת חבילות.

  1. צור מאגר GitHub חדש, רצוי פרטי אם הוא מכיל קוד פנימי (המפתחות עצמם לא נמצאים בקובץ).
  2. העלה את הקובץ הזה ושנה את שמו ל־index.html.
  3. במאגר פתח Settings ← Pages, בחר מקור פרסום מהענף הראשי (לרוב main) ומהתיקייה /(root), ושמור.
  4. פתח את כתובת האתר ש־GitHub Pages מציג והגדר את החיבור. פרטי החיבור נשמרים בדפדפן שבו הזנת אותם, ולא עוברים אוטומטית לדפדפנים אחרים.
⚠️
אם מתקבלת שגיאת CORS או שגיאת רשת, ייתכן שהשרת/תוסף האבטחה בחנות חוסם בקשות מהדומיין של GitHub Pages. יש לאפשר את מקור האתר שלך בשרת בצורה מצומצמת ומבוקרת. אל תפתור זאת באמצעות חשיפת מפתחות בכתובת URL.

הערות חשובות

כדי למנוע הפתעות בעת ניהול החנות.

  • המחירים מוצגים בשקלים (₪). ודא שמטבע החנות ב־WooCommerce מוגדר לשקל חדש (ILS).
  • מוצר עם וריאציות (Variable product) עשוי לקבל מחירים נפרדים לכל וריאציה. במסך זה ניתן לעדכן את שמו, התיאור והתמונה, אבל שינוי המחיר של הווריאציות צריך להתבצע בממשק WooCommerce.
  • העלאת תמונה דורשת שסיסמת היישום תהיה זמינה ושהמשתמש יהיה מורשה להעלות מדיה.
  • מפתחות API שהוגדרו ב־WooCommerce ניתן לבטל מתוך מסך REST API. מומלץ ליצור מפתח ייעודי לאפליקציה זו.
